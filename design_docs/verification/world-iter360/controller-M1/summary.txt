## A5-instrument — why run 1 was red, measured

test binary's temp files then land under that long path, and in

test's expected string is the uncut line. Paired control at fa5b9183, same test alone:

  (A5-instrument-control-long-gotmpdir.txt);

"matched" for the wrong reason). Run 2 removes only the GOTMPDIR export and re-runs all 212 rows.

path is short. CI's temp path is short, so CI is unaffected; a developer with a long TMPDIR sees
