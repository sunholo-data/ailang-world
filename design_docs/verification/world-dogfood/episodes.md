# World episodes — evidence ledger (row 187)

Every real task run through AILANG World, one row each. Generated by `scripts/trial/ledger.py` from the runner's episode records and transcripts; regenerate after each episode:

    python3 scripts/trial/ledger.py --root ~/.ailang/state/trial-2026-10-16 --prs <rig>/trial/prs.json

**What this shows:** real, merged or reviewable work delivered through World alone (World MCP tools plus sandboxed operator commands), what it cost (wall time, World calls, tokens), and how it graded. Every graded result is also committed in World as a `world/task-outcome/v1` record (the "outcomes" column).

**What it does not show:** a comparison. Every row is a World episode, with no same-task plain-shell arm, so nothing here says World is faster or cheaper than a shell on real work. The controlled comparison so far is the clause-4 floor (benchmark tasks: Δ 0 for both agents, overhead −17.9% for Claude Code and −5.7% for Codex; `../world-floor-final-2026-10-15/`).
