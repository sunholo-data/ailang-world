```bash
TS_CTL="2026-09-08T06:19:00Z"; TS_ARM=""
ts_try() {  # $1=arm $2=value $3=outfmt -> stdout, rc from date
  case "$1" in
    bsd) TZ=UTC date -j -f '%Y-%m-%dT%H:%M:%SZ' "$2" "+$3" 2>/dev/null ;;
    gnu) date -u -d "$2" "+$3" 2>/dev/null ;;
  esac
}
ts_resolve_arm() {  # ONCE, before F9/F10; positive control on the parser itself (rule 3a)
  local a; for a in bsd gnu; do
    if [ "$(ts_try "$a" "$TS_CTL" '%Y-%m-%dT%H:%M:%SZ')" = "$TS_CTL" ]; then TS_ARM="$a"; return 0; fi
  done
  echo "✗ timestamp parser unusable: neither BSD nor GNU date parsed the control value" >&2; exit 2
}
validate_ts() {  # $1=value $2=label(path or --since); prints nothing on ok; F10 message + exit 2 otherwise
  local v="$1" label="$2" canon epoch now
  case "$v" in
    [0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]T[0-9][0-9]:[0-9][0-9]:[0-9][0-9]Z) ;;
    *) echo "✗ watermark invalid: $label (not-ISO8601 '$v')" >&2; exit 2 ;;
  esac
  canon="$(ts_try "$TS_ARM" "$v" '%Y-%m-%dT%H:%M:%SZ')"
  if [ -z "$canon" ]; then echo "✗ watermark invalid: $label (not-canonical '$v')" >&2; exit 2; fi
  if [ "$canon" != "$v" ]; then echo "✗ watermark invalid: $label (not-canonical '$v' → '$canon')" >&2; exit 2; fi
  epoch="$(ts_try "$TS_ARM" "$v" '%s')"; now="$(date -u +%s)"
  if [ "$epoch" -gt $((now + SKEW)) ]; then echo "✗ watermark invalid: $label (future '$v' > now+${SKEW}s)" >&2; exit 2; fi
}
```

### The suite's rules

- **Scratch:** `SCRATCH="$(mktemp -d "$(pwd)/.g0_scratch.XXXXXX")"`;
  `trap 'chmod -R u+rw "$SCRATCH" 2>/dev/null; rm -rf "$SCRATCH"' EXIT`.
- **Only fixture builder:** `make_json() { cat > "$1"; }` reading literal lines from a heredoc.
  **No helper synthesises a comment, an author, a body, or a meta count.** Each arm writes its own
  `<n>.json` and `<n>.meta.json` by heredoc, including deliberately broken shapes.
- **Stub gh** — `make_stub_gh <out> <fixture-dir> <argv-log>` writes a bash script that appends
  `"$*"` as one line to `<argv-log>`, serves `<dir>/<n>.json` for `issue view <n> …`, serves
  `<dir>/<n>.meta.json` for `api repos/<owner>/<name>/issues/<n>`, and otherwise prints
  `stub gh: no fixture` to stderr and exits 1. Reference shape:

  ```bash
  make_stub_gh() {  # $1=out $2=fixture-dir $3=argv-log
    local out="$1" dir="$2" log="$3"
    {
      echo '#!/usr/bin/env bash'
      echo 'set -u'
      printf 'printf "%%s\\n" "$*" >> "%s"\n' "$log"
      printf 'dir="%s"\n' "$dir"
      echo 'case "$1 $2" in'
      echo '  "issue view") f="$dir/$3.json" ;;'
      echo '  "api repos/"*) f="$dir/${2##*/}.meta.json" ;;'
      echo '  *) echo "stub gh: no fixture" >&2; exit 1 ;;'
      echo 'esac'
      echo '[ -f "$f" ] || { echo "stub gh: no fixture" >&2; exit 1; }'
      echo 'cat "$f"'
    } > "$out"
    chmod +x "$out"
  }
  ```
  `gh-timeout` and `gh-failed` use their own two-line stubs (`/bin/sleep 3`; `exit 7`).
- **Every instrument invocation** is `bash "$SCRIPT_UT" …` — never `sh`, never the login shell —
  with `--repo test/test --self sunholo-voight-kampff --gh-bin "$stub"` unless the arm says otherwise.
  Fixture issues in synthetic arms are numbered `5` (and `6` where two are needed) so that no
  synthetic arm can accidentally satisfy a snapshot assertion.
- **Every `ok`/`not ok` message begins with its arm name** (`ok report exits 0`, `not ok report
  rc=$rc: …`) — the drill's red-set extraction is `awk '/^not ok/{print $3}' | sort -u`.
- **Row-90 property** — enforced by what each arm is allowed to grep:
  classification arms (1-5): `crash:` lines by `at=` + one token, rc; floor arms (7-14, 21, 22,
  23, 24): own message, rc, argv-log emptiness where stated; `report` alone greps `verdict:`;
  `snapshot-*` alone grep a full `issue:` line and `control:`; watermark arms (19-22) grep
  `watermark:`/`since:` only; `no-bodies` greps sentinel absence + `url=`; `signature-source`
  its three lines. A grep outside an arm's allowance is a defect even if green.
- **Timestamps in synthetic fixtures** are literal `YYYY-MM-DDTHH:MM:SSZ` strings; `--since` values
  in the arms are literals except `watermark-strict`'s `now−60s`, computed as
  `python3 -c 'import datetime as d; print((d.datetime.now(d.timezone.utc)-d.timedelta(seconds=60)).strftime("%Y-%m-%dT%H:%M:%SZ"))'`.
