## 0. Binding constraints (each is restated in the milestone it governs)

1. **Fakes, temp stores and test keys only (D-WORLD-109 = A).** Every world and credentials store is
   under `t.TempDir()` (`dbPathOf`). Keys come from the checked-in fixtures
   `host/approval/testdata/sshsig/{ed25519,p256}.pub` (generated by real `ssh-keygen`, SHA-pinned by
   SG1) or from `approvaltest.NewSigner(seed)`. **No `ssh-keygen` runs in this sprint**, no fixture
   is generated or edited, and nothing opens `~/.ailang/world`, `~/.ssh`, a real credentials store,
   a real daemon or `/dev/tty`. No mint, no publish.
2. **The FIFO rule (planner P1, carried).** A file named by an operator flag is opened with
   `os.OpenFile(path, os.O_RDONLY|syscall.O_NONBLOCK, 0)`, then `f.Stat()` **on the descriptor**,
   refusing a non-regular file and a size over the bound, then read once through
   `io.LimitReader(f, max+1)`. Never `os.Open`: it blocks on a FIFO before any fstat (measured, C5).
   This overrides the design's §2.10 N4 / §2.7 F9 text ("open the file"), which a reviewer wrote
   and the carve-out applied verbatim.
3. **The reader rule (planner P2, carried).** The approver y/N uses the new error-aware
   `readTermLineErrWithin` and confirms only on `ok && err == nil && line ends with "\n" &&
   isYes(line)`. `readTermLine` and `readTermLineWithin` (`session.go:477`, `:486`) are **not
   changed** (design R8).
4. **The bound.** Enrol and revoke each wait at most `approverConfirmBudget = 120 * time.Second`,
   through the existing `sessionEnv.after` seam (`session.go:36-37`). The read-only pre-check handle
   is **closed before** the prompt; the writer lock (`openCredentialsForSession`) is taken only after
   `y`.
5. **One mutant per new branch** (§4: 91 mutants: 69 for M3, 22 for M4). Every mutant row names the single test that kills
   it. A refusal arm asserts its exit code by constant **and** its exact text **and** that nothing was
   written.
6. **Exit codes by constant**: `exitOK = 0`, `exitUsage = 1`, `exitFatal = 2`
   (`cmd/ailang-worldd/main.go:72-74`, measured). Every refusal before a write is `exitUsage`; a
   failure at or after the writer open is `exitFatal`.
7. **Reflective completeness** for the one struct a check claims to cover completely in this sprint:
   `approval.SignedApproval` (RC1, M4b).
8. **No `t.Parallel()`** in any new test (the touched packages write files and swap package vars).
9. **Bisectable.** Each sub-milestone ends compiling — `go build ./...` **and** `go vet <pkg>`
   (`go build` does not compile `_test.go`) — with its own tests and every earlier sub-milestone's
   tests green.
10. **Context roots.** Exactly three new production roots, pinned in `TestProductionContextRoots`:
    `approver.go|runApproverList|Background: 1` (M3d), `…|runApproverEnroll|Background: 2` (M3e),
    `…|runApproverRevoke|Background: 2` (M3g). Sprint 3's K8 makes the last one 3 (Appendix B).
11. **No git writes by the executor** (§7). The controller rebuilds commits from snapshots.

### 1.4 Premises found false or incomplete at HEAD (each routed around minimally)

- **P1 — (carried, re-measured C5) "open, then fstat the descriptor" with a plain open blocks on a
  FIFO.** Design §2.10 N4 / §2.7 F9 [r2] text says to open then fstat; `os.Open` blocks in `open(2)`
  before any fstat. Routed by §0.2 (`O_NONBLOCK`). The design's mutant "`f.Stat()` replaced by a path
  `Lstat`" is not killable by a FIFO arm without a concurrent swap; it is replaced by MUT-N4-NONBLOCK
  (the FIFO arm hits its 5 s guard) and MUT-N4-REGULAR (the FIFO reads as 0 bytes; the text check
  fires).
- **P2 — (carried) design §2.10a's sketch calls `readTermLineWithin`**, contradicting its own [r2]
  reader contract. Routed by §0.3.
- **P3 — NEW: Appendix A's two reader mutants are equivalent.** Appendix A says "N10-ERR (`err ==
  nil` dropped) [CA4 `y`+error arm]; N10-NL (newline-suffix dropped) [CA4 `y`+EOF arm]". Because
  `ReadString` returns `err != nil` **iff** the line lacks the delimiter (C6), each check alone
  refuses exactly what the other refuses: dropping either one changes nothing. Measured (C12): both
  survive CF1 and every other test. Routed: both checks stay (the design's contract names both); the
  counted mutant is **MUT-N10-PARTIAL** (both dropped → `y`+EOF confirms; killed by CF1); the two
  single drops are listed as known-equivalent, not counted.
- **P4 — NEW: design §2.3's `NotAdmittedError` and `BindingError` have no `Error()` method**, so the
  sketch's `return nil, &NotAdmittedError{…}` does not compile as an `error`. Routed: §2.5 adds both
  methods with fixed text (message-only, no mutant).
- **P5 — NEW: no exported way to get a stored blob's key type.** Routed by D3 (`KeyFromBlob`).
- **P6 — NEW: the design's sprint-2 split (M4 store+authority, then M5 approve) is not bisectable.**
  C1 (challenge required in the consume) and C6 (`AND challenge = ?`) refuse every typed approve unless
  `approve.go:213-214` passes the row's challenge, and A1 (`ErrApprovedBySetByCaller`) refuses it
  unless the same line stops passing `ApprovedBy: "tty"`. Decoding the row's challenge is the design's
  F4, listed under M5. So C1/C6 + A1–A5 + the `approve.go:213-214` edit + F4/CR11 must land in **one**
  sub-milestone. The existing tests that build a consume also need the challenge: `host/store/mint_requests_test.go:352`
  (`okConsume`), `:582` (`TestConcurrentApprovalsMintOnce`), and `host/authority/mint_request_test.go:56`,
  `:67`, `:109`, `:132` — the design's V34 names only `:56` and `:78`. Not this sprint's scope; routed
  into Appendix B (B-D1).
- **P7 — Line drift from sprint 1** (citations the design makes into the two files sprint 1 changed):
  `host/store/mint_requests.go` `RequestConsume` `:234-239` → **`:237-241`**; `MintSessionForRequest`
  `:243` → **`:246`**; `BeginTx` `:256` → **`:259`**; `at := rc.Clock()` `:261` → **`:264`**; the guarded
  `UPDATE` `:265` → **`:268`**; `classifyConsume` `:287` → **`:290`**; `OlderCredentialsStoreError`
  `:65-69` → **`:61-72`** (now `{Path, Version, Need, Feature}`); `credentials.go:432` (bound-mint
  refusal) → **`:437`**. Appendix B uses the new numbers.
- **P8 — (carried, sprint-1 P7) `isYes` accepts `yes`** as well as `y`. Kept, as every attended verb

// approverConfirmBudget is the fixed y/N budget of approver enroll and revoke, counted from the
// moment the prompt is written (design §2.10a [r1], Q7: a constant, so a script cannot widen it).
const approverConfirmBudget = 120 * time.Second

// confirmApproverAct shows prompt at /dev/tty and returns exitOK only on a y typed within
// approverConfirmBudget, as a complete line with no read error (design §2.10a [r2]). Every other
// outcome returns its refusal code having written nothing. It is called with no store handle
// open, so no writer lock is held while it waits.
func confirmApproverAct(env sessionEnv, stderr io.Writer, prefix, prompt, nothing string) int {
	if env.after == nil { // N9a / K4a
		fmt.Fprintf(stderr, "%sinternal error: no prompt timer (sessionEnv.after)\n", prefix)
		return exitFatal
	}
	term, err := env.openTerminal()
	if err != nil { // N9 / K4
		fmt.Fprintf(stderr, "%srefusing: no controlling terminal (%v); %s. %s\n", prefix, err, nothing, sessionTTYFix)
		return exitUsage
	}
	defer func() { _ = term.Close() }() // closed on every return
	fmt.Fprint(term, prompt)            // the budget starts here
	line, rerr, ok := readTermLineErrWithin(term, approverConfirmBudget, env.after)
	if !ok { // N10a / K5a
		fmt.Fprintf(stderr, "%sno answer within %s; %s\n", prefix, approverConfirmBudget, nothing)
		return exitUsage
	}
	if rerr != nil || !strings.HasSuffix(line, "\n") || !isYes(line) { // N10 / K5: EOF, read error, partial line, not y
		fmt.Fprintf(stderr, "%saborted (not confirmed); %s. fix: run it again and type y at the prompt\n", prefix, nothing)
		return exitUsage
	}
	return exitOK
}

// readTermLineErrWithin is readTermLineWithin keeping the read's error and the RAW line
// (untrimmed, so a missing newline shows): ok is false when after(d) fires first. readTermLine
// drops the error and keeps a partial line (design R8), so the approver verbs use this instead.
// The one-shot rule applies: a timed-out read leaves its goroutine blocked until the process exits.
func readTermLineErrWithin(r io.Reader, d time.Duration, after func(time.Duration) <-chan time.Time) (line string, err error, ok bool) {
	type result struct {
		line string
		err  error
	}
	ch := make(chan result, 1)
	go func() {
		l, e := bufio.NewReader(r).ReadString('\n')
		ch <- result{l, e}
	}()
	select {
	case res := <-ch:
		return res.line, res.err, true
	case <-after(d):
		return "", nil, false
	}
}

// readRegularFileCapped reads path once: it opens non-blocking (so a FIFO cannot stall the
// open, plan P1), checks the open DESCRIPTOR (a regular file of at most max bytes), and reads
// through readCapped. Sprint 3's approve --signature reuses it.
func readRegularFileCapped(path string, max int64) ([]byte, error) {
	f, err := os.OpenFile(path, os.O_RDONLY|syscall.O_NONBLOCK, 0)
	if err != nil {
		return nil, err
	}
	defer func() { _ = f.Close() }()
	info, err := f.Stat()
	if err != nil {
		return nil, err
	}
	if !info.Mode().IsRegular() {
		return nil, fmt.Errorf("%s is not a regular file", path)
	}
	if info.Size() > max {
		return nil, fmt.Errorf("%s is %d bytes, over the %d-byte bound", path, info.Size(), max)
	}
	return readCapped(f, max)
}

// readCapped reads r to its end and refuses more than max bytes (a file that grew after its
// fstat).
func readCapped(r io.Reader, max int64) ([]byte, error) {
	b, err := io.ReadAll(io.LimitReader(r, max+1))
	if err != nil {
		return nil, err
	}
	if int64(len(b)) > max {
		return nil, fmt.Errorf("grew past the %d-byte bound while being read", max)
	}
	return b, nil
}

package approval

// Row 201 A1b (design_docs/planned/w-world-approvals-by-key-a1b.md §2.3): the pure signature
// law. A mint request is approved by signature only when it is admitted, the approver is
// enrolled, active and not ahead of the clock, and its key's SSHSIG over the request's exact
// message (stored digest, row challenge, row expiry) verifies. No I/O here (coding standard S2).

import (
	"bytes"
	"errors"
	"fmt"
)

// SignedApproval is a verified signature approval. Its fields are unexported, so only
// ApproveBySignature, in this package, can return one with ok set; the zero value binds nothing.
type SignedApproval struct {
	ok        bool
	digest    [32]byte
	challenge [32]byte
	expiry    int64
	name      string
	format    string
	key       []byte
}

// SignatureInput is what ApproveBySignature judges.
type SignatureInput struct {
	Admit     AdmitInput // the existing admission input (row times, consumed, both digests)
	Challenge [32]byte   // the request row's challenge
	Signature []byte     // the armored SSHSIG
	Approver  Approver   // the enrolled row the signature's key names
}

// NotAdmittedError is admission's refusal on the signature path (P1): the request is consumed,
// expired, ahead of the clock, or its bytes do not match their digest.
type NotAdmittedError struct{ Verdict Verdict }

func (e *NotAdmittedError) Error() string {
	return fmt.Sprintf("approval: the request is not admitted (%s)", e.Verdict)
}

// ErrNotVerified is any use of a SignedApproval that ApproveBySignature did not return.
var ErrNotVerified = errors.New("approval: not a verified signature approval")

// BindingError is a verified approval used for a request it was not made for.
type BindingError struct{ Field string } // "digest" | "challenge" | "expiry"

func (e *BindingError) Error() string {
	return fmt.Sprintf("approval: the signature approval was made for another request (%s differs)", e.Field)
}

// ApproveBySignature is the signature law (P1-P6, in this order): admission first, so a replay
// says "already used"; the approver's state before the cryptography, so a revoked key says
// "revoked" even when its signature is good.
func ApproveBySignature(in SignatureInput) (*SignedApproval, error) {
	if v := Admit(in.Admit); v != Admitted { // P1
		return nil, &NotAdmittedError{Verdict: v}
	}
	if !ApproverNamePattern.MatchString(in.Approver.Name) { // P2
		return nil, ErrApproverName
	}
	if in.Approver.Format != FormatSSH { // P3
		return nil, ErrApproverFormat
	}
	if in.Approver.RevokedAt != 0 { // P4
		return nil, ErrApproverRevoked
	}
	if in.Admit.Now < in.Approver.EnrolledAt { // P5
		return nil, ErrApproverClockBehind
	}
	if err := VerifyApproval(in.Signature, in.Admit.StoredDigest, in.Challenge, in.Admit.ExpiresAt, in.Approver.Key); err != nil { // P6
		return nil, err
	}
	return &SignedApproval{ok: true, digest: in.Admit.StoredDigest, challenge: in.Challenge,
		expiry: in.Admit.ExpiresAt, name: in.Approver.Name, format: in.Approver.Format,
		key: bytes.Clone(in.Approver.Key.Blob)}, nil
}

// Binds reports whether s is a verified approval of exactly this digest, challenge and expiry.
func (s *SignedApproval) Binds(digest, challenge [32]byte, expiry int64) error {
	if s == nil || !s.ok { // B1
		return ErrNotVerified
	}
	if s.digest != digest { // B2
		return &BindingError{Field: "digest"}
	}
	if s.challenge != challenge { // B3
		return &BindingError{Field: "challenge"}
	}
	if s.expiry != expiry { // B4
		return &BindingError{Field: "expiry"}
	}
	return nil
}

// ---- M4b ----

// ApprovedBy is the approved_by value, format ":" name ("ssh:mark-mac"); "" unless verified.
func (s *SignedApproval) ApprovedBy() string {
	if s == nil || !s.ok { // B5
		return ""
	}
	return s.format + ":" + s.name
}

// Use is what the consume binds in SQL: the approver's name, format and key (a copy).
func (s *SignedApproval) Use() (name, format string, key []byte, ok bool) {
	if s == nil || !s.ok { // B6
		return "", "", nil, false
	}
	return s.name, s.format, bytes.Clone(s.key), true
}
